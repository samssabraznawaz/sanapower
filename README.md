# SaNaPower

Power analysis and sample size for the F tests, in your web browser: multiple linear regression (the test of R², and
the test of the R² increase), one-way ANOVA, and one effect of a factorial ANOVA or ANCOVA. A priori (the sample size
you need), post hoc (the power of a given sample) and sensitivity (the smallest effect a fixed sample can detect). The
result comes with a sentence for your methods section. Nothing is installed, no data file is needed and nothing you
type leaves your device; once the page has been opened it also works offline.

**Open it:** https://<your-github-user>.github.io/sanapower/ (the address GitHub Pages shows for this repository)

**Manual:** `SaNaPower-Manual-0.1.0.pdf` in this repository (12 pages, with worked examples and the reporting sentence).

The results use the noncentral F distribution and were compared with published worked examples (Faul et al., 2009) and
with independent calculations. SaNaPower contains these four designs only; it has no t-tests, correlation, chi-square,
repeated-measures or multivariate power analysis.

SaNaPower is part of SaNaSoft (SaNaPLS, SaNaQual, SaNaML), developed by Prof. S. Sabraz Nawaz and Prof. Ghazanfar Ali.
